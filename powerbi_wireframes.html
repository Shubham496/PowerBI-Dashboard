Page 01 DAX Blueprint

Executive Overview

Answering: "How is the business performing across revenue, profit, customers, and product returns?"

🎯 Executive KPI Tracking & Performance Diagnostics

📐 Required DAX Measures & Formulas (12 measures defined)

[CY Sales] Revenue
Calculates the total revenue for the current context/year by multiplying order quantity by the unit selling price.
CY Sales = 
CALCULATE(
    SUMX(Sales, Sales[OrderQuantity] * Sales[ProductPrice]),
    'Calander'[Date]
)
Math Logic: Σ (OrderQuantity × ProductPrice) Format / Return: Currency ($#,##0.00)
[PY Sales] Time Intelligence
Shifts the calendar date filter back exactly one year to evaluate prior year revenue across identical dates.
PY Sales = 
CALCULATE(
    [CY Sales],
    SAMEPERIODLASTYEAR('Calander'[Date])
)
Math Logic: Sales evaluated over [Date - 1 Year] Format / Return: Currency ($#,##0.00)
[Sales Delta] Variance
Absolute net dollar variance between current year sales and prior year sales.
Sales Delta = [CY Sales] - [PY Sales]
Math Logic: CY Sales - PY Sales Format / Return: Currency ($#,##0.00)
[Sales Growth] Growth %
Percentage increase or decrease in sales compared to prior year, guarded against divide-by-zero errors.
Sales Growth = 
DIVIDE([Sales Delta], [PY Sales], 0)
Math Logic: (CY Sales - PY Sales) / PY Sales Format / Return: Percentage (+0.0%;-0.0%;0.0%)
[Sales Formatted] Card Display
Formatted text card label with dynamic scaling (M for Millions, K for Thousands) for clean executive card display.
Sales Formatted = 
VAR Amount = [CY Sales]
RETURN
SWITCH(
    TRUE(),
    ISBLANK(Amount), "$0.00",
    ABS(Amount) >= 1000000, "$" & FORMAT(Amount / 1000000, "0.00") & "M",
    ABS(Amount) >= 1000, "$" & FORMAT(Amount / 1000, "0.0") & "K",
    "$" & FORMAT(Amount, "#,##0.00")
)
Math Logic: Dynamic scalar formatting Format / Return: String text
[Sales Growth Formatted] Indicator
Produces an executive callout badge with Unicode indicator arrows (▲/▼) and formatted percentage.
Sales Growth Formatted = 
VAR GrowthVal = [Sales Growth]
VAR DeltaVal = [Sales Delta]
RETURN
SWITCH(
    TRUE(),
    ISBLANK([PY Sales]), "New",
    DeltaVal > 0, "▲ +" & FORMAT(GrowthVal, "0.0%"),
    DeltaVal < 0, "▼ " & FORMAT(GrowthVal, "0.0%"),
    "— 0.0%"
)
Math Logic: Unicode directional formatted string Format / Return: String text
[CY Gross Profit] Profitability
Calculates gross margin dollars by subtracting total product manufacturing/procurement cost from total sales.
CY Total Cost = 
CALCULATE(
    SUMX(Sales, Sales[OrderQuantity] * RELATED('Products lookup'[ProductCost])),
    'Calander'[Date]
)

CY Gross Profit = [CY Sales] - [CY Total Cost]
Math Logic: Revenue - COGS (Cost of Goods Sold) Format / Return: Currency ($#,##0.00)
[CY Gross Margin] Profitability %
Gross margin percentage showing operational efficiency of generated sales.
CY Gross Margin = 
DIVIDE([CY Gross Profit], [CY Sales], 0)
Math Logic: Gross Profit / CY Sales Format / Return: Percentage (0.0%)
[CY Customers] Audience
Unique count of active purchasing customers within the filtered time period.
CY Customers = 
CALCULATE(
    DISTINCTCOUNT(Sales[CustomerKey]),
    'Calander'[Date]
)
Math Logic: DistinctCount(CustomerKey) Format / Return: Whole Number (#,##0)
[Customer Growth] Growth %
Year-over-year percentage change in active buying customer base.
PY Customers = 
CALCULATE([CY Customers], SAMEPERIODLASTYEAR('Calander'[Date]))

Customer Growth = 
DIVIDE([CY Customers] - [PY Customers], [PY Customers], 0)
Math Logic: (CY Customers - PY Customers) / PY Customers Format / Return: Percentage (+0.0%;-0.0%)
[Return Rate] Quality
Ratio of units returned compared to total units sold across the active filter context.
CY Quantity = 
CALCULATE(SUM(Sales[OrderQuantity]), 'Calander'[Date])

CY Return Quantity = 
CALCULATE(
    SUM('Returns Data'[ReturnQuantity]),
    USERELATIONSHIP('Returns Data'[ReturnDate], 'Calander'[Date])
)

Return Rate = 
DIVIDE([CY Return Quantity], [CY Quantity], 0)
Math Logic: Returned Units / Units Sold Format / Return: Percentage (0.00%)
[CY Repeat Rate] Retention
Percentage of buying customers who placed more than one distinct order in the active year/period.
CY Repeat Customers = 
CALCULATE(
    COUNTROWS(
        FILTER(
            VALUES(Sales[CustomerKey]),
            CALCULATE(DISTINCTCOUNT(Sales[OrderNumber])) > 1
        )
    ),
    'Calander'[Date]
)

CY Repeat Rate = 
DIVIDE([CY Repeat Customers], [CY Customers], 0)
Math Logic: Repeat Customers (>1 Order) / Total Customers Format / Return: Percentage (0.0%)

💡 Recommended Improvements & Power BI Best Practices
  • Date Table Sort Order: Ensure 'Calander'[Short Month] is explicitly sorted by 'Calander'[Month Number] in the model to avoid alphabetical sorting (Apr, Aug, Dec...).
  • Returns Relationship Activation: The model has an inactive link between 'Returns Data'[ReturnDate] and 'Calander'[Date]. In DAX, explicitly wrap return measures in USERELATIONSHIP('Returns Data'[ReturnDate], 'Calander'[Date]) or activate the relationship in Power BI model view.
  • Performance Optimization via Variables: In [Sales Growth Formatted] and other composite measures, use VAR to evaluate base measures exactly once per row/cell rather than recalculating multiple times inside SWITCH statements.

[CY Sales per Customer] Customer Value
Average sales generated per active customer within the selected timeframe.
CY Sales per Customer = 
DIVIDE([CY Sales], [CY Customers], 0)
Math Logic: Total Sales / Distinct Purchasing Customers Format / Return: Currency ($#,##0.00)
[PY Sales per Customer] Time Intelligence
Prior year benchmark for sales per customer over the same dates.
PY Sales per Customer = 
CALCULATE(
    [CY Sales per Customer],
    SAMEPERIODLASTYEAR('Calander'[Date])
)
Math Logic: Sales per Customer evaluated over prior year Format / Return: Currency ($#,##0.00)
[Sales per Customer Growth] Growth %
Percentage growth in customer average spend year-over-year.
Sales per Customer Growth = 
DIVIDE([CY Sales per Customer] - [PY Sales per Customer], [PY Sales per Customer], 0)
Math Logic: Δ Sales per Customer / PY Sales per Customer Format / Return: Percentage (+0.0%;-0.0%)
[Quantity Growth] Volume Growth
Calculates volume growth in units sold year-over-year to distinguish volume expansion from price inflation.
PY Quantity = 
CALCULATE([CY Quantity], SAMEPERIODLASTYEAR('Calander'[Date]))

Quantity Growth = 
DIVIDE([Quantity Delta], [PY Quantity], 0)
Math Logic: (CY Units - PY Units) / PY Units Format / Return: Percentage (+0.0%;-0.0%)
[CY Gross Cost] COGS
Total procurement/manufacturing product cost for units sold in current year.
CY Gross Cost = 
CALCULATE(
    SUMX(Sales, Sales[OrderQuantity] * RELATED('Products lookup'[ProductCost])),

[Gross Margin Color Format] Color Measure
Dynamic HEX color code generator for conditional formatting rules on matrix tables and scatter bubbles.

VAR MarginVal = [CY Gross Margin]

SWITCH(

)
Math Logic: Hex string based on gross margin tiers Format / Return: Hex Color string (#RRGGBB)

Customer Performance

Answering: "How effectively are we acquiring, retaining, and monetizing customers?"

🎯 Cohort Acquisition, Churn Diagnostics & Demographic Value

📐 Required DAX Measures & Formulas (5 measures defined)

[CY New Customers] Acquisition
Counts customers whose lifetime first transaction ever occurred within the selected calendar timeframe.
CY New Customers = 
VAR CustomersInPeriod = VALUES(Sales[CustomerKey])
VAR MinSelectedDate = MIN('Calander'[Date])
VAR MaxSelectedDate = MAX('Calander'[Date])
RETURN
COUNTROWS(
    FILTER(
        CustomersInPeriod,
        VAR FirstEverDate = 
            CALCULATE(
                MIN(Sales[OrderDate]), 
                REMOVEFILTERS('Calander')
            )
        RETURN
            FirstEverDate >= MinSelectedDate && FirstEverDate <= MaxSelectedDate
    )
)
Math Logic: Count of CustomerKeys where Min(Lifetime OrderDate) ∈ Filtered Dates Format / Return: Whole Number (#,##0)
[CY Lost Customers] Churn
Calculates customer churn: customers who placed an order in the prior year but have not made any purchases in the current period.
CY Lost Customers = 
VAR CurrentCustomers = 
    CALCULATETABLE(
        VALUES(Sales[CustomerKey]),
        'Calander'[Date]
    )
VAR PriorYearCustomers = 
    CALCULATETABLE(
        VALUES(Sales[CustomerKey]),
        SAMEPERIODLASTYEAR('Calander'[Date])
    )
RETURN
COUNTROWS(
    EXCEPT(PriorYearCustomers, CurrentCustomers)
)
Math Logic: Count(PriorYearCustomers \ CurrentYearCustomers) Format / Return: Whole Number (#,##0)
[CY One-Time Customers] Segmentation
Counts customers who placed exactly one order in the current timeframe, indicating potential churn risk.
CY One-Time Customers = [CY Customers] - [CY Repeat Customers]

CY One-Time Rate = 
DIVIDE([CY One-Time Customers], [CY Customers], 0)
Math Logic: Total CY Customers - Repeat Customers Format / Return: Whole Number (#,##0)
[CY Orders per Customer] Engagement
Average transaction frequency per buying customer across the period.
CY Orders per Customer = 
DIVIDE([CY Orders], [CY Customers], 0)
Math Logic: Total Orders / Total Buying Customers Format / Return: Decimal Number (0.0)
[Customer Retention Rate] Retention
Proportion of prior year active customers who returned to make at least one purchase in the current year.
Customer Retention Rate = 
VAR PriorYearCustomers = 
    CALCULATETABLE(
        VALUES(Sales[CustomerKey]),
        SAMEPERIODLASTYEAR('Calander'[Date])
    )
VAR RetainedCustomers = 
    CALCULATETABLE(
        VALUES(Sales[CustomerKey]),
        'Calander'[Date],
        PriorYearCustomers
    )
RETURN
DIVIDE(COUNTROWS(RetainedCustomers), COUNTROWS(PriorYearCustomers), 0)
Math Logic: Retained Customers / Prior Year Customers Format / Return: Percentage (0.0%)

[Product Sales Rank] Ranking

    ALLSELECTED('Products lookup'[ProductName]),

[Avg Selling Price] Pricing

Average unit procurement cost for units sold.

DIVIDE([CY Total Cost], [CY Quantity], 0)
Math Logic: Total COGS / Total Units Sold Format / Return: Currency ($#,##0.00)
[Unit Margin] Unit Economics
Dollar contribution margin generated per unit sold.
Unit Margin = [Avg Selling Price] - [Avg Product Cost]
Math Logic: Avg Selling Price - Avg Product Cost Format / Return: Currency ($#,##0.00)
[Return Rate Status Color] Conditional Color
Hex color generator for icons and backgrounds to highlight return quality issues.
Return Rate Status Color = 
SWITCH(
    TRUE(),

Math Logic: Color flag based on return threshold (>3% Red, 2-3% Amber, <2% Green) Format / Return: Hex Color string
